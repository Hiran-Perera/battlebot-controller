_Battle Bot Controller Firmware_

An Arduino-based control system for a 3-channel battle bot with safety, current protection, and drive inversion features.



Features
- Dual drive motor control (CH1, CH2)
- Weapon motor with current sensing and trip protection (CH3)
- Drive invert switch (CH5)
- 3-position safety mode switch (CH6)
- Weapon ramping and restart after trip
- Failsafe motor stop on lost RX signal
- Compatible with FlySky FS-i6 receiver and BTS7960 motor drivers



Pin Mapping(NANO)

___________________________________________________
| Function        | Pin | Description             |
|-----------------|-----|-------------------------|
| CH1             | 8   | Right motor input       |
| CH2             | 13  | Left motor input        |
| CH3             | 7   | Weapon input            |
| CH5             | 4   | Invert switch           |
| CH6             | 2   | 3-position mode switch  |
| MOT_A_LPWM      | 5   | Drive Motor A forward   |
| MOT_A_RPWM      | 3   | Drive Motor A reverse   |
| MOT_B_LPWM      | 6   | Drive Motor B forward   |
| MOT_B_RPWM      | 9   | Drive Motor B reverse   |
| MOT_W_LPWM      | 10  | Weapon Motor forward    |
| MOT_W_RPWM      | 11  | Weapon Motor reverse    |
| currentW        | A1  | Weapon current sensor   |
| WeaponSW        | A2  | Weapon enable signal    |
| enable          | A3  | Drive enable            |
| enableW         | 12  | Weapon enable           |




Requirements
- Arduino Nano / Uno
- FlySky FS-i6 Receiver
- BTS7960 Motor Drivers
- ACS Current Sensor (20mV/A) 100A sensor
